Overview
Single-page assignment, three problems, that ties together combinational design, latch / self-referential-memory analysis, and CMOS gate identification. Problem 1 asks you to design a two-output combinational circuit from basic gates that realises a given 4-row truth table. Problem 2 asks you to describe a circuit built from three 2-input AND gates feeding a single 3-input OR gate, where the OR output Q* is fed back into the top and bottom ANDs — the hint to look for self-consistent output states is the giveaway that this is a memory cell, not a pure combinational gate. Problem coverage
Problem 1 — combinational design from a truth table. The given table is (A,B,O1,O2) = (0,0,0,1), (0,1,1,1), (1,0,1,0), (1,1,1,1). Output 1 is HIGH on every row except (A,B) = (0,0), which is exactly OR: O1 = A + B (annotation "OR: Q₁ = 1"). Output 2 is LOW only on the single row (A,B) = (1,0), which the student labels "only 0 when only A = 1"; equivalently O2 = NOT(A · NOT B) = NOT A + B (an "implication" gate, A → B). The sketched realisation uses an inverter on B feeding into one input of a NAND together with A (and an OR gate to produce Q₁ = A + B), giving Q₁ and Q₂ from a small handful of basic gates. Problem 2 — self-referential AND-AND-AND-OR cell. Inputs A and B drive the middle 2-input AND directly (A·B). The top and bottom ANDs each take one external input and one feedback input from the OR's own output Q*: top AND = A·Q*, bottom AND = B·Q*. The 3-input OR sums these, so the self-consistency condition is Q* = A·Q* + B·Q* + A·B = Q*(A + B) + A·B. Reading off the four input combinations: (0,0) forces Q* → 0 (reset); (1,1) forces Q* → 1 (set); (1,0) and (0,1) leave Q* = Q*, i.e. the cell holds whatever value it had on the previous cycle. The student's conclusion — "this circuit exhibits the behaviour of self-referential memory and utilises said memory in its logic" — captures it exactly: it is a one-bit memory whose next-state function is the same logical expression evaluated using the current state. Problem 3 — six-transistor CMOS gate identification. The annotations identify Q₁, Q₂, Q₅ as P-mos and Q₃, Q₄, Q₆ as n-mos, with A controlling the gates of Q₁ and Q₃ and B controlling the gates of Q₂ and Q₄; the intermediate node between the two stacks drives the gates of the output pair Q₅ and Q₆. Tracing the topology: Q₁ and Q₂ are stacked in series between +V and the intermediate node X (so the pull-up path exists only when A = 0 and B = 0), while Q₃ and Q₄ are in parallel between X and GND (so X is pulled low whenever A = 1 or B = 1). That makes the first stage a CMOS NOR with X = NOT(A + B). The second stage Q₅/Q₆ is a CMOS inverter on X, so Out = NOT(X) = A + B. Walking the four (A,B) combinations using the standard CMOS conventions (n-mos: V_gs = V_g − V_s, g = 1 ON, g = 0 OFF — P-mos: V_gs = V_s − V_g, g = 0 ON, g = 1 OFF) reproduces the truth table A B → Out: 0 0 → 0, 1 0 → 1, 0 1 → 1, 1 1 → 1, which is the OR function — and the student notes the gate "behaves like an OR gate," with the textbook OR symbol and truth table drawn alongside for direct comparison.

How to use this page
Read each problem as one of three job-types. (1) Going from a truth table to a gate network: identify which rows the output is HIGH (or LOW) on, recognise the canonical pattern (only-(0,0)-low ⇒ OR; only-(A=1, B=0)-low ⇒ A → B = Ā + B), and pick the smallest gate set that realises it. (2) Analysing a circuit with feedback: do not try to reduce it as pure combinational logic; instead, write down the self-consistency equation (output = function of inputs and itself), then case-split on the inputs to see whether each combination forces the state to a unique value or leaves it free — the "free" cases are the hold/memory rows. (3) Identifying a CMOS gate from its transistor schematic: label every transistor as n-mos or P-mos, write down which input controls which gate, then walk the four (A,B) combinations using the rule "n-mos pull-down ON when its gate is HIGH, P-mos pull-up ON when its gate is LOW," and read off whether the output node is connected to +V or to GND. For multi-stage CMOS, do this stage-by-stage: identify each stage's function (NOR if the P-mos pair is in series; NAND if the P-mos pair is in parallel; inverter if a single P-mos / n-mos pair is driven by the same node), then compose. The combination of all three problems traces the same staircase as the lecture notes — gate truth tables → bistable memory → transistor-level realisation — but here you are asked to walk it in reverse on a concrete schematic.
