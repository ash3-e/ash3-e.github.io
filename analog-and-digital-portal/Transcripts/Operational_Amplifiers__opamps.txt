Operational Amplifiers (op-amps)
Overview
Single-page lecture notes assembling the canonical op-amp topologies under negative feedback: open-loop transfer V_out = A_OL(V_in⁺ − V_in⁻) and the resulting golden rules, the non-inverting amplifier with gain (1 + R₁/R₂), the inverting amplifier with gain −R₁/R₂, the unity-gain (voltage-follower) buffer for impedance transformation, summing and differential amplifiers, the op-amp integrator V_out = −(1/RC)∫V_in dt, the active integrator's frequency-dependent generalisation V_out = −(Z₁/Z₂)V_in, and a transimpedance (current-to-voltage) amplifier. The page emphasises that as long as A_OL is large the gain is set by the resistor ratio, not by A_OL. This transcript is a page-specific reconstruction for preview and search.

Key equations

$$V_{out}=A_{OL}\,(V_{in}^{+}-V_{in}^{-}),\qquad A_{OL}\approx 10^{4}\text{–}10^{6}\gg 1$$

$$\text{Properties: }Z_{in}\approx 10^{6}\text{–}10^{14}\ \Omega,\ Z_{out}\approx 1\text{–}100\ \Omega,\ -V_{S}<V_{out}<+V_{S}$$

$$\text{Golden rules: }V_{in}^{+}=V_{in}^{-},\quad I_{in}=0,\quad I_{1}=I_{2}$$

$$\text{Non-inverting amp: }V_{in}^{-}=\frac{R_{2}}{R_{1}+R_{2}}V_{out}$$

$$V_{out}=\left(\frac{R_{1}+R_{2}}{R_{2}}\right)V_{in}=\left(1+\frac{R_{1}}{R_{2}}\right)V_{in}$$

$$V_{out}=\frac{A_{OL}}{1+A_{OL}\cdot R_{2}/(R_{1}+R_{2})}V_{in}\xrightarrow{A_{OL}\gg 1}\left(1+\frac{R_{1}}{R_{2}}\right)V_{in}$$

$$\text{Inverting amp: }V_{in}^{-}=V_{in}^{+}=0\Rightarrow I_{1}=\frac{V_{in}-0}{R_{1}}=I_{2}=\frac{0-V_{out}}{R_{2}}$$

$$V_{out}=-\frac{R_{2}}{R_{1}}V_{in}\quad\text{(inverting amplifier gain)}$$

$$\text{Unity-gain buffer: }V_{out}=V_{in}\ (\text{any }R_{out}\text{)}$$

$$\text{Summing amp: }V_{out}=-\frac{R_{L}}{R_{1}}(V_{in}^{1}+V_{in}^{2})$$

$$\text{Differential amp: }V_{out}=-\frac{R_{2}}{R_{1}}(V_{in,1}-V_{in,2})$$

$$\text{For }R_{1}=500\ \Omega,R_{2}=1000\ \Omega,V_{in,1}=3\ \text{V},V_{in,2}=2\ \text{V}\Rightarrow V_{out}=-2\ \text{V}\to 4\ \text{V (with sign convention)}$$

$$V_{out}(t)=-\frac{Q}{C}=-\frac{1}{C}\int_{0}^{t}I_{1}(t')\,dt'=-\frac{1}{RC}\int_{0}^{t}V_{in}(t')\,dt'\quad\text{(active integrator)}$$

$$\text{Passive integrator only when }\omega\gg \frac{1}{RC}$$

$$V_{out}=-\frac{Z_{1}}{Z_{2}}V_{in}\quad\text{(frequency-dependent gain)}$$

$$\text{Integrator: }Z_{1}=\frac{1}{i\omega C},\ Z_{2}=R\Rightarrow V_{out}=\frac{-1}{i\omega RC}V_{in}$$

$$\left|\frac{Z_{1}(\omega)}{Z_{2}(\omega)}\right|\ll A_{OL}(\omega)\quad\text{(condition for the gain expression to hold)}$$

$$\text{Transimpedance amp: }V_{out}=-I_{in}R\quad\text{(current → voltage, transimpedance gain }=R\text{)}$$

$$\text{Useful for non-ideal current sources: }V^{-}=\text{virtual ground},\ \text{no voltage drop across source}$$

$$\text{If non-inverting input is grounded, the inverting input is the "virtual ground"}$$

How to use this page
Read each displayed relation as solving one of four jobs: invoking the golden rules to set V_in⁺ = V_in⁻ and zero input current, writing KCL at the inverting node to convert that constraint into an output expression, ratioing two impedances Z_1/Z_2 to extend the result to AC, or using a unity-gain buffer / transimpedance stage to reshape impedance without changing the signal value. That is the logic tying the handwritten algebra together.
