# Plasma Toroid Sky-Guided Reference Site

Single-page static reference and guide for the sky-guided plasma toroid PCB edition paired with a 1L xenon globe and smart thermal base.

## Run Locally

Open `index.html` directly, or serve the folder with any static server:

```powershell
python -m http.server 8080
```

Then visit `http://localhost:8080/`.

The site uses plain HTML, CSS, and ES modules. There is no build step, bundler, storage, or framework runtime.
